TikTok Spark Code 宏配置

刘海屏 iPhone / TikTok 法语界面 / AssistiveTouch 屏幕按钮触发

这个页面是执行手册和测试记录器。真正的点击宏需要在 iPhone 的 AssistiveTouch 里录制，页面会帮你按固定流程配置、验证和记录失败点。

录制前状态

iPhone 设置

  • 显示缩放使用默认模式。
  • TikTok App 语言固定为法语。
  • 从同一台刘海屏 iPhone 录制和执行。
  • 网络保持稳定，避免页面加载时宏提前点击。

标准起点

每次触发宏前，都先停在目标视频播放页，右侧分享按钮可见，视频页面没有弹窗或浮层。

TikTok 视频页 → 分享/更多 → Paramètres publicitaires → Autorisation publicitaire → Gérer → Copier le code

AssistiveTouch 配置

1
打开 AssistiveTouch 设置 → 辅助功能 → 触控 → AssistiveTouch → 打开。
2
创建新手势 进入“创建新手势”，从 TikTok 视频页开始，慢速录制实际点按。每次页面跳转后停 1-2 秒再点下一步。
3
保存为“复制广告码” 录制结束后保存手势，名字固定用“复制广告码”，方便后面在悬浮菜单里识别。
4
加入顶层菜单 AssistiveTouch → 自定顶层菜单 → 添加“复制广告码”。以后每条视频只点悬浮球，再点这个手势。
建议第一次录制只做“从视频页打开广告设置页”，确认坐标稳定后再录完整流程。完整宏一旦跑偏，先回到视频页再重跑，不要在中间页面连续触发。

录制动作脚本

A
点分享/更多入口 从视频页右侧分享按钮开始。等待分享面板完全展开。
B
点广告设置入口 在分享面板底部工具区选择法语界面里的广告设置入口，通常是“Paramètres publicitaires”相关图标。
C
开启 Autorisation publicitaire 进入设置页后，如果开关关闭，点击打开；如果已打开，录制宏可能会误关，建议单独录“未授权视频”宏和“已授权视频复制 code”宏。
D
点 Gérer 等待页面刷新出 code 区域后，点击“Gérer”。
E
点 Copier le code 在底部菜单出现后点击“Copier le code”，等待顶部提示“Code vidéo copié”。
